# 3weirdaxes
The 3weirdaxes Political Quiz measures individuals' political values by the metrics of left and right-wing economics, progressive and conservative cultural values, and idealist and materialist worldviews. This project is a fork of the [8values](https://8values.github.com) project, made to include a dimension of philosophical orientation.
